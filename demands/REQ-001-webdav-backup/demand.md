# 需求：WebDAV 备份客户端（鸿蒙）

## 基本信息

- 需求编号: REQ-001
- 项目代号: webdav-backup
- 优先级: P0
- 状态: 草稿
- 创建日期: 2026-09-16
- 关联平台: HarmonyOS 4.2 + HarmonyOS NEXT

## 需求描述

市面上面向 OpenList / 自建 WebDAV 的手机备份应用普遍存在以下痛点：

- 强制收费 / 限量 / 上传限速
- 仅支持单一平台（iOS / Android），鸿蒙版本缺失
- 同步策略粗暴（不上传缩略图就报错、断点续传失败、删除云端旧文件）
- 隐私问题（数据经第三方中转）

本项目目标：交付一款**开源、个人用、鸿蒙原生**的 WebDAV 备份客户端，对接自建 OpenList WebDAV 服务，把手机本地文件（照片、视频、自定义目录）安全、断点、增量地备份到 WebDAV，**不主动删除云端任何资源**。

## 用户故事

- **作为一个**鸿蒙手机用户
  **我想要**配置一个（或多个）WebDAV 端点
  **以便于**把相册视频与指定目录自动备份到自己的 OpenList 服务

- **作为一个**经常拍摄视频的用户
  **我想要**应用在网络恢复后自动续传中断的大文件
  **以便于**不会因为切换网络或后台被杀而丢数据

- **作为一个**关注隐私的用户
  **我想要**App 仅与我的 WebDAV 通信、不删除任何云端文件
  **以便于**我可以确信我的备份数据只受自己控制

- **作为一个**需要快速确认上传状态的用户
  **我想要**在 App 内查看上传历史（成功 / 失败 / 队列）
  **以便于**及时发现并重试失败的文件

## 功能要求

### F1. WebDAV 端点管理

- F1.1 支持新增 / 编辑 / 删除多个 WebDAV 端点
- F1.2 每个端点独立配置：服务器 URL、用户名、密码、根目录路径、备份开关
- F1.3 凭据使用鸿蒙 KeyStore 加密存储，明文不落盘
- F1.4 端点支持"连接测试"功能（HEAD 请求验证）

### F2. 备份源配置

- F2.1 支持两种备份源：相册、任意目录
- F2.2 相册备份：监测"图库"新增的照片 / 视频
- F2.3 目录备份：用户自选任意可访问目录（下载、文档、自定义文件夹）
- F2.4 多源 / 多端点可任意组合，每个组合是一个"备份任务"

### F3. 同步触发

- F3.1 实时监测：Photo Access Kit 监听相册；fsnotify 监听自定义目录
- F3.2 定时对账：默认每 6 小时一次全量对账（用户可调：1h / 6h / 12h）
- F3.3 网络恢复自动触发：检测到网络可用时立即跑一次对账
- F3.4 "仅 Wi-Fi" 选项（默认开启，可关闭）

### F4. 增量同步

- F4.1 本地指纹库：每文件记录 (path, size, mtime, sha1)
- F4.2 sha1 计算采用首 1MB + 末 1MB 抽样哈希，避免大文件长时间占用 IO
- F4.3 与 WebDAV LIST 返回的远端条目对账；本地存在且远端不存在 → 上传
- F4.4 远端文件被外部修改 / 删除时**不主动同步删除到本地**

### F5. 断点续传

- F5.1 文件分块上传，默认 chunk = 4MB
- F5.2 HTTP `PUT` 携带 `Content-Range: bytes=start-end/`
- F5.3 上传前 `HEAD` 探测远端已上传字节，从断点继续
- F5.4 续传次数无限，仅受用户主动取消或远端校验失败终止

### F6. 失败处理与重试

- F6.1 单文件上传失败采用指数退避重试（最多 5 次：1s / 2s / 4s / 8s / 16s）
- F6.2 重试用尽后进入"失败列表"，等待用户手动重试
- F6.3 网络断开时全部上传任务暂停，恢复后自动续跑

### F7. 历史记录与状态可视化

- F7.1 每文件一条记录：路径、源端点、上传时间、字节数、状态（成功 / 失败 / 进行中 / 排队）
- F7.2 状态页签：成功 / 失败 / 上传中 / 排队
- F7.3 通知中心：上传完成 / 失败时发送系统通知

### F8. 释放本地资源

- F8.1 上传成功后，对应本地文件标记为"已备份"（仅在 App 内标记）
- F8.2 **App 不主动删除用户原始文件**
- F8.3 提供"已备份"列表视图，用户可手动决定是否清理本地

### F9. WebDAV 资源预览

- F9.1 图片（jpg / png / webp / heic）内建预览
- F9.2 视频（mp4 / mov / m4v）内建预览（HTTP Range 拉流）
- F9.3 音频（mp3 / m4a / flac）内建播放
- F9.4 文档（pdf / doc / xlsx）调系统应用打开

### F10. 安全与隐私

- F10.1 WebDAV 通信走 HTTPS（用户配置可选 HTTP，但不推荐）
- F10.2 不上传任何遥测 / 分析数据
- F10.3 凭据本地 KeyStore 加密，不上传
- F10.4 应用启动时显示一次"数据只备份到你的 WebDAV"提示

## 非功能要求

- **性能**：单文件首字节延迟 < 500ms（LAN）；指纹库查询 < 50ms / 千条
- **存储**：本地指纹库增长线性可控；冷数据定期归档到压缩表
- **可用性**：App 必须在鸿蒙 4.2 与鸿蒙 NEXT 同时可运行
- **后台**：实时监测需要后台运行权限，需用户主动授予
- **国际化**：MVP 仅简体中文；预留多语言架构（l10n 资源目录）
- **可观测性**：本地日志（最多 7 天轮转），不上传

## 范围控制

### MVP（必做）

- F1 ~ F10 全部纳入验收

### 二期（不做）

- 缩略图缓存与相册视图增强
- 多账号 / 端点分组
- WebDAV 端反向同步到手机
- 端到端加密（用户数据上传前加密）

### 永久不做

- 删除 WebDAV 远端资源
- 第三方数据中转
- 应用内广告 / 推送营销
